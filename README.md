# 🎨 Diseño de Interfaces Web

Repositorio con las **prácticas y ejercicios** de la asignatura **Diseño de Interfaces Web**, perteneciente al ciclo de **Desarrollo de Aplicaciones Web (DAW)**.

El objetivo de este repositorio es aplicar principios de **diseño visual, usabilidad y experiencia de usuario (UI/UX)** en interfaces web, combinando diseño y maquetación con buenas prácticas frontend.

---

## 📚 Contenidos del repositorio

El repositorio está organizado por **prácticas numeradas**, cada una enfocada en distintos conceptos de diseño de interfaces.

### 🧩 Prácticas realizadas

- **P2-1 / P2-2 / P2-3 / P2-4 / P2-5**
  - Maquetación web
  - Uso correcto de HTML y CSS
  - Diseño responsive
  - Jerarquía visual
  - Tipografía y colores

- **PRWEB01**
  - Práctica global de diseño web
  - Aplicación de principios de usabilidad
  - Estructuración clara de la interfaz

- **Diseños y bocetos**
  - Prototipos y esquemas realizados con herramientas de diseño
  - Archivos `.excalidraw` para planificación visual

---

## 🛠️ Tecnologías y herramientas utilizadas

- **HTML5**
- **CSS3**
- **Flexbox**
- **Grid Layout**
- **Diseño Responsive**
- **Excalidraw**
- **Buenas prácticas de UI/UX**

---

## 🎯 Objetivo del repositorio

- Diseñar interfaces web claras y usables
- Aplicar principios de **UX/UI**
- Mejorar la experiencia del usuario
- Crear diseños responsive
- Sentar bases sólidas de maquetación web
